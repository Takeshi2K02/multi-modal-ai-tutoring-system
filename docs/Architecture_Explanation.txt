EXECUTIVE SUMMARY
-----------------
This document provides a comprehensive structural audit of the 'Agentic AI Core' powering the EduSynth tutoring platform. The architecture leverages a Tree of Thought (ToT) synthesis model integrated with Multimodal RAG and Reinforcement Learning (RL) telemetry to deliver personalized, grounded pedagogical interventions.

1. TREE OF THOUGHT (TOT) GRAPH STRUCTURE
----------------------------------------
The core reasoning engine is implemented as a directed acyclic graph (DAG) using the LangGraph framework, orchestrating a State Machine that mimics human cognitive decomposition.

* Nodes: retrieve_context, expand_frontier, evaluate_frontier, prune_frontier, finalize_output.
* Logic determines the "Active Trajectory" via a Beam Search algorithm (Width=2, Branching=3). 
* The UI displays the path with the highest cumulative Path Score.

2. MULTIMODAL RAG INTEGRATION
-----------------------------
The system employs a "Grounded-First" retrieval strategy to ensure technical accuracy in Business Intelligence (BI) topics.

* Grounded Evidence: Uses ChromaDB (local_data) for context retrieval (top_k=5).
* Prevention of Context Drift: System prompts enforce strict alignment with retrieved RAG evidence, preventing generic LLM hallucinations.

3. REINFORCEMENT LEARNING (RL) & CV FEEDBACK LOOP
-------------------------------------------------
The agent adapts its behavior based on a closed-loop feedback system from Computer Vision (CV) telemetry.

* Affect Score Mapping: CV engagement scores (0.00-1.00) are mapped to reward values.
* Pedagogical Policy: The system switches between 'Explanation' and 'Design Challenge' modes based on engagement trends and proficiency scores calculated in snapshot.py.

4. DATA PERSISTENCE & HYDRATION
-------------------------------
Uses MongoDB for session management and content caching.

* Collections: learning_sessions, generated_content, student_progress.
* State Reconciliation: The system checks for existing content in 'generated_content' before triggering the LLM, allowing students to review previous branches without latency.

5. COMPONENT MAPPING
--------------------
