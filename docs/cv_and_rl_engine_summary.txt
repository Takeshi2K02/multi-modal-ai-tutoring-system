--- cv/backend/services/ml_models.py ---
Purpose: Core CV inference classes. EngagementModel combines a ViT emotion
         classifier (fine-tuned or HuggingFace fallback), MediaPipe
         FaceLandmarker (gaze + eye closure), and PoseLandmarker (posture).
         ContentModel uses zero-shot BART to detect the topic of OCR text.
Inputs:  EngagementModel.predict() — BGR numpy frame (np.ndarray)
         ContentModel.predict()    — OCR text string
Outputs: EngagementModel: dict with emotion, emotion_confidence, gaze,
         posture, eye_state
         ContentModel: topic string (e.g. "mathematics")
Status:  Real implementation (models loaded from disk or HuggingFace Hub)

--- cv/backend/services/engagement_service.py ---
Purpose: Orchestrates one tracking cycle: decodes a base64 webcam frame,
         calls EngagementModel, optionally runs EasyOCR on a screen capture,
         calculates a weighted engagement score, applies a 3-frame stability
         buffer, and returns a flat result dict.
Inputs:  frame_data (base64 str), screen_data (base64 str, optional),
         material_id (str, optional)
Outputs: dict — emotion, emotion_conf, engagement_score, engagement_state,
         gaze, posture, ocr_excerpt, context_match, engagement_context_state
Status:  Real implementation

--- cv/backend/services/content_service.py ---

--- rl_engine/src/env/tutor_env.py ---
Purpose: Gymnasium environment modelling an adaptive tutoring session. Holds
         a 14-dimensional student state, a 9-action discrete action space,
         a reward function combining engagement + accuracy + confidence, and
         a sync_with_db method to pull live CV/performance data from MongoDB.
Inputs:  reset(student_id: str) — student profile ID from JSON file
         step(action: int) — one of 9 pedagogical actions (0-8)
         sync_with_db(user_id: str) — MongoDB connection string via env var
Outputs: observation (np.ndarray shape (14,)), reward (float), terminated
         (bool), info (dict)
Status:  Real implementation

--- rl_engine/src/env/student_sim.py ---
Purpose: Rule-based student simulator used during training. Applies fixed
         delta effects (attention, accuracy, confusion, boredom) per action
         with small Gaussian noise. Also contains helper samplers for CV and
         agentic state.
Inputs:  simulate_student(state: dict, action: int)
Outputs: dict — attention, recent_acc, time_on_task, confusion, boredom
Status:  Real implementation

--- rl_engine/src/engine/rl_engine.py ---

         checkpoint and exposes a decide() method.
Inputs:  model_path (str), env (VecEnv); observation (np.ndarray) at runtime
Outputs: dict — action_id (int), confidence (float, always 1.0),
         timestamp (float)
Status:  Real implementation (confidence is a placeholder constant, not
         a true probabilistic estimate)
